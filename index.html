/01 · Data pipeline

Vanguard Credit Monitoring

High-throughput credit data pipeline

Ingests 1M+ financial records per run, with peaks around 100K records/s, while keeping live credit state and client alerts current.

JavaSpring BootKafkaApache FlinkClickHouseMySQL
  • Replaced a synchronous design needing 66 minutes per batch and ~166× the provisioned IOPS. End-to-end latency is now ~5 minutes.
  • Bounded producer-consumer buffer feeding 8 writer threads, with high/low-watermark hysteresis that parks and resumes the poller. Idempotent upserts make retries safe.
  • Removed InnoDB gap-lock deadlocks with READ COMMITTED and disjoint key ranges per writer.
  • Traced a thread-scaling ceiling to false sharing, padded the counters onto separate cache lines, and showed near-linear scaling with JMH.

ProjectPulse

Java 21Spring Boot 3Spring SecurityPostgreSQLKafkaLangChain4j

02 · Field notes

Production bugs,
found and fixed.

Concurrency · MySQL

Writers deadlocking each other

Symptom
Concurrent writer threads deadlocked under load.
Cause
InnoDB gap locks overlapping between writers.
Fix
READ COMMITTED plus a disjoint key range per writer, so lock conflicts can't happen.
CPU · JMH

Threads that refused to scale

Symptom
Adding writer threads stopped improving throughput.
Cause
False sharing on per-thread counters.
Fix
Counters on separate cache lines. Near-linear scaling to 8 threads, confirmed with JMH.
Messaging · RabbitMQ

Emails arriving late

Symptom
Delayed email delivery after broker and client restarts.
Cause
Stale channels; consumers never came back.
Fix
Capped-backoff reconnect and automatic consumer resubscription. No manual recovery needed.
Events · Webhooks

Leadership alerted twice

Symptom
Duplicate alerts on branch creation.
Cause
In-app events delivered again through GitLab webhooks.
Fix
Every event is deduplicated on its identity, so a redelivery does nothing.
Resilience · LLM providers

Reports quietly degrading

Symptom
Report sections fell back to templates as if the provider were down.
Cause
Transient rate-limit errors were treated as outages.
Fix
Retry with backoff, a circuit breaker and provider failover.
